# 01. Claude Code 是什么

## 一句话介绍

**Claude Code 是 Anthropic 官方推出的"终端版 AI 结对编程助手"**，它在你的命令行里运行，能够直接读写你本地项目的文件、执行命令、调用工具，并以自然语言对话的方式帮你完成编码任务。

## 它与 Cursor / GitHub Copilot 的核心区别

| 维度 | Claude Code | Cursor | GitHub Copilot |
| --- | --- | --- | --- |
| **形态** | 命令行 CLI（也支持 IDE 插件） | 独立 IDE（基于 VSCode 分叉） | IDE 插件（VSCode/JetBrains 等） |
| **核心交互** | 对话式任务（Agent 模式） | 对话 + 内联编辑 | 代码补全为主，Chat 为辅 |
| **文件操作权限** | 可直接读写多文件、执行 shell | 同等能力，但在 IDE 内 | 主要是补全，较少主动改文件 |
| **上下文窗口** | 200K+，支持超大项目 | 依赖所选模型 | 较小，偏局部 |
| **底层模型** | Anthropic Claude（Sonnet/Opus） | 多模型可选（含 Claude） | OpenAI GPT 系列为主 |
| **适用场景** | 复杂任务自动化、脚本化、CI | 日常交互式开发 | 写代码时的轻量辅助 |

**一句话总结**：
- 需要**"写代码时实时提示"** → Copilot
- 需要**"在编辑器里聊着改代码"** → Cursor
- 需要**"把一个完整任务丢给 AI 执行"**、可脚本化/自动化 → **Claude Code**

> 三者不冲突，很多开发者会 **同时使用**：Copilot 负责补全，Cursor 负责交互式修改，Claude Code 负责复杂多文件重构和自动化任务。

## Claude Code 能做什么

### 1. 代码理解
- 读取整个项目结构，回答架构问题
- 解释某个函数/模块的作用
- 追踪数据流、调用链

### 2. 代码生成与修改
- 从需求描述生成新功能
- 跨多个文件的重构（改名、提取、拆分）
- 修复已知 bug

### 3. 调试与排障
- 根据报错信息定位问题
- 运行测试，分析失败原因，自动修复
- 追溯 Git 历史查找回归问题

### 4. 测试与质量
- 为现有代码补写单测 / 集成测试
- 生成 E2E 测试脚本
- 做代码审查（Code Review）

### 5. 文档与知识
- 根据源码生成 README / API 文档
- 把会议纪要/需求转成 Issue 列表
- 生成架构图（Mermaid）

### 6. 工程化自动化
- 写 CI/CD 配置
- 一键升级依赖并修复 breaking change
- 跨仓库统一变更

## 核心设计理念

1. **Agent-first**：它不是"补全工具"，而是能接受一个目标、自主拆解并执行的"智能体"。
2. **本地优先**：代码、文件都在你本地，不会默认上传到云端训练。
3. **可审计**：每次文件修改、命令执行都会在终端显示，你可以选择拒绝。
4. **可组合**：通过 Hooks、Subagents、MCP 等机制，能和团队现有工具栈深度集成。

## 什么时候不适合用 Claude Code

- **非常简单的一行改动**：直接手写比描述需求还快。
- **高度创意性设计工作**：UI 设计稿、产品命名等更适合专门的工具。
- **对正确性要求极高且无法验证的场景**：如修改加密算法、安全关键代码，必须人工严格 review。
- **离线环境**：Claude Code 依赖网络调用 Anthropic API。
