## 学习建议

### 新手必读顺序
1. **先通读 01**，理解"容器是什么"，别急着动手
2. **跟着 02 装好环境**，确保 `docker run hello-world` 能成功
3. **03 和 04 要边看边敲**，每个命令都亲手跑一遍
4. **05 是分水岭**，学会写 Dockerfile 就算真正入门了
5. **06-08 按需深入**，遇到具体问题再回头查
6. **09 是加分项**，了解 nerdctl 让你跟上行业趋势
7. **10 是毕业考试**，从头到尾完成一个项目才算学会

### 避坑指南
- 不要一上来就啃 Kubernetes，先把 Docker 吃透
- Windows 用户建议用 WSL2 + Docker Desktop，体验最好
- 镜像加速器一定要配，否则拉镜像慢到怀疑人生
- 养成 `docker system prune` 清理的习惯，磁盘会感谢你
- 命令记不住很正常，多查 `docker --help`，用多了自然就会
